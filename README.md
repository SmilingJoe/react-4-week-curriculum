# React 4-Week Curriculum for Senior Engineers

A comprehensive React learning curriculum designed specifically for senior-level software engineers with extensive experience in JavaScript, Node.js, SPAs, and Vue.js.

## Overview

This curriculum provides a structured, hands-on approach to mastering React in 4 weeks. Each day includes:
- **Detailed concept explanations** with comparisons to Vue.js and other familiar technologies
- **Multiple code examples** demonstrating best practices
- **Practical coding assignments** to reinforce learning
- **Senior-level insights** on architecture, performance, and production patterns

## Who This Is For

This curriculum is tailored for:
- **Senior software engineers** transitioning to React
- Developers with **strong JavaScript fundamentals**
- Engineers experienced with **Vue.js** looking for direct comparisons
- **Node.js developers** building full-stack applications
- Professionals seeking **production-ready** React knowledge

## Learning Approach

1. **Concept Introduction**: Each day starts with clear explanations of core concepts
2. **Vue.js Comparisons**: Direct comparisons help leverage existing SPA knowledge
3. **Code Examples**: Multiple real-world examples with detailed explanations
4. **Daily Assignments**: Hands-on problems to solidify understanding
5. **Best Practices**: Senior-level guidance on architecture and optimization

## Prerequisites

- Strong JavaScript (ES6+) knowledge
- Experience with SPAs (preferably Vue.js)
- Familiarity with Node.js and npm
- Understanding of async/await and Promises
- Basic knowledge of build tools

## Getting Started

1. Clone this repository
2. Start with Week 1, Day 1
3. Read the lesson document
4. Study the code examples
5. Complete the daily assignments
6. Build and test your solutions
7. Review best practices before moving forward

## Setting Up Your Development Environment

```bash
# Install Node.js (if not already installed)
# Visit https://nodejs.org/

# Create a new React project with Vite
npm create vite@latest my-react-app -- --template react

# Navigate to project
cd my-react-app

# Install dependencies
npm install

# Start development server
npm run dev
```

## Recommended Tools

- **Code Editor**: VS Code with React/ES7 snippets
- **Browser Extension**: React Developer Tools
- **Linting**: ESLint with `eslint-plugin-react-hooks`
- **Build Tool**: Vite (modern, fast alternative to Create React App)
